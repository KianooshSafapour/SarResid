    35→## API contract cheat-sheet for view builders
    36→- Tasks: GET /api/tasks?scope=mine|all → {tasks}; POST {title,description,type,priority,assignedToId,dueDate,points}; PATCH /api/tasks/[id] {action:'start'|'pause'|'done'|'reopen', pauseNote} → {task, awarded} (done auto-awards points); DELETE /api/tasks/[id].
    37→- SOPs: GET /api/sops → {sops:[{steps:[{title,detail}]}]}; POST {title,category,steps:[{title,detail}]} (managers); PATCH {id,title,category,steps}; DELETE ?id=.
    38→- Wall: GET /api/wall → {posts}; POST {title,content}; DELETE ?id=.
    39→- Notes: GET /api/notes → {notes} (private); POST {content,color}; PATCH {id,content,color,pinned}; DELETE ?id=.
    40→- Feedback: GET /api/feedback → {feedback, canManage}; POST {type:'ANON'|'IDEA', content, anonymous}; PATCH {id,status,response,points} (managers; points>0 awards idea owner).
    41→- Planograms: GET /api/planograms → {planograms:[{layout:[[productId|null]]}], productMap:{id:{name,stock,reorderLevel,category}}}; POST {name,section,rows,cols}; PATCH [id] {layout,status:'PUBLISHED'}; DELETE [id].
    42→- Refill (merchandiser → storekeeper): create Task via POST /api/tasks with type 'TASK' assigned to SK user, or use customer-requests? No — RefillRequest model exists but no dedicated route yet; use tasks instead.
    43→- Sales: customers GET/POST/PATCH /api/customers; preorders GET ?scope=all|mine|cashier, POST {customerId,customerName,items:[{productId,name,qty,price}],note}, PATCH [id] {action:'cashier_edit'|'done'|'cancel', items}.
    44→- Customer requests: GET /api/customer-requests; POST {productName,productId,notes} (increments count if same name); DELETE ?id=.
    45→- Gamification: GET /api/gamification → {leaderboard, awards, recentAwards, stats, badges}; POST /api/gamification/award {userId,points,reason} (managers).
    46→- Admin: users GET/POST /api/users, PATCH/DELETE /api/users/[id]; activity GET /api/activity?entity=&q=; holidays GET/POST/DELETE /api/holidays, POST /api/holidays/sync.
    47→- Dashboard: GET /api/dashboard → {kpi, series, chequeSeries, overdueOrders, todayDeliveriesList, lowStockList, leaderboard, wall, activities, customerReqs, myTasks, toAccount, pendingChequesList}.
