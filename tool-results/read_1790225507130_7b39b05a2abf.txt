   125→/** پارس امن پیکربندی ذخیره‌شده (رشتهٔ JSON یا آبجکت) — سازگار با پیکربندی round-17؛ در خطای کلان null */
   126→export function parseAvatarStyle(raw: string | Record<string, unknown> | null | undefined): AvatarStyle | null {
   127→  if (!raw) return null
   128→  let o: Record<string, unknown> | null = null
   129→  if (typeof raw === 'string') {
   130→    try { o = JSON.parse(raw) as Record<string, unknown> } catch { return null }
   131→  } else if (typeof raw === 'object') o = raw
   132→  if (!o || typeof o !== 'object') return null
   133→
   134→  const clamp = (v: unknown, max: number) => {
   135→    const n = Number(v)
   136→    return Number.isFinite(n) ? Math.min(max, Math.max(0, Math.round(n))) : -1
   137→  }
   138→  const has = (k: string) => o![k] !== undefined && o![k] !== null && o![k] !== ''
   139→  // فیلدهای اصلی نسخهٔ ۱ باید موجود باشند وگرنه پیکربندی نامعتبر است (سقوط به حرف اول نام)
   140→  if (!has('skin') || !has('hair') || !has('hairColor') || !has('eyes') || !has('mouth') || !has('outfit') || !has('outfitColor') || !has('accessory') || !has('bg')) return null
   141→
   142→  const skin = clamp(o.skin, AVATAR_SKINS.length - 1)
   143→  const hairColor = clamp(o.hairColor, AVATAR_HAIR_COLORS.length - 1)
   144→  const eyes = clamp(o.eyes, AVATAR_EYES.length - 1)
   145→  const mouth = clamp(o.mouth, AVATAR_MOUTHS.length - 1)
   146→  const outfit = clamp(o.outfit, AVATAR_OUTFITS.length - 1)
   147→  const outfitColor = clamp(o.outfitColor, AVATAR_OUTFIT_COLORS.length - 1)
   148→  const bg = clamp(o.bg, AVATAR_BGS.length - 1)
   149→  if ([skin, hairColor, eyes, mouth, outfit, outfitColor, bg].some((x) => x < 0)) return null
   150→
   151→  let hair = AVATAR_HAIRS.some((h) => h.k === o!.hair) ? String(o!.hair) : ''
   152→  // مهاجرت: «روسری» قدیم → حجاب روسری
   153→  let hijab = AVATAR_HIJABS.some((h) => h.k === o!.hijab) ? String(o!.hijab) : 'none'
   154→  let hijabColor = clamp(o.hijabColor ?? 0, AVATAR_HIJAB_COLORS.length - 1)
   155→  if (hijabColor < 0) hijabColor = 0
   156→  if (!hair && o!.hair === 'scarf') {
   157→    hijab = 'scarf'
   158→    hijabColor = Number(o!.hairColor) === 5 ? 7 : 0 // بورdeaux قدیم → بورdeaux جدید، بقیه → سیاه
   159→    hair = 'short' // زیر روسری پنهان است
   160→  }
   161→  if (!hair) return null
   162→
   163→  let accessory = AVATAR_ACCESSORIES.some((a) => a.k === o!.accessory) ? String(o!.accessory) : ''
   164→  let glasses = AVATAR_GLASSES.some((g) => g.k === o!.glasses) ? String(o!.glasses) : 'none'
   165→  // مهاجرت: عینکِ قدیم از اکسسوری جدا شد
   166→  if (!accessory && o!.accessory === 'glasses') {
   167→    glasses = glasses === 'none' ? 'round' : glasses
   168→    accessory = 'none'
   169→  }
   170→  if (!accessory) return null
   171→
   172→  const beard = AVATAR_BEARDS.some((b) => b.k === o!.beard) ? String(o!.beard) : 'none'
   173→  const brows = Math.min(2, Math.max(0, clamp(o.brows ?? 0, 2) < 0 ? 0 : clamp(o.brows ?? 0, 2)))
   174→  const bool = (v: unknown) => v === true || v === 'true' || v === 1
   175→  const emojiN = Number(o.emoji)
   176→  const emoji = Number.isFinite(emojiN) ? Math.min(7, Math.max(-1, Math.round(emojiN))) : -1
   177→
   178→  return { skin, hair, hairColor, eyes, mouth, outfit, outfitColor, accessory, bg, hijab, hijabColor, beard, brows, blush: bool(o.blush), freckles: bool(o.freckles), glasses, emoji }
   179→}

   186→function shade(hex: string, f: number): string {
   187→  const n = parseInt(hex.slice(1), 16)
   188→  const ch = (v: number) => Math.min(255, Math.max(0, Math.round(v * f)))
   189→  const r = ch((n >> 16) & 255), g = ch((n >> 8) & 255), b = ch(n & 255)
   190→  return `#${((r << 16) | (g << 8) | b).toString(16).padStart(6, '0')}`
   191→}

   700→/* ── ابزار فشرده‌سازی تصویر سمت کلاینت (برش مربع + تغییر اندازه + JPEG زیر ۳۰۰KB) ── */
   701→export function downscaleImageToDataUrl(file: File, max = 256, square = true): Promise<string> {
   702→  return new Promise((resolve, reject) => {
   703→    const reader = new FileReader()
   704→    reader.onerror = () => reject(new Error('خواندن فایل ناموفق بود'))
   705→    reader.onload = () => {
   706→      const img = new Image()
   707→      img.onerror = () => reject(new Error('فایل تصویر معتبر نیست'))
   708→      img.onload = () => {
   709→        const scale = Math.min(1, max / Math.max(img.width, img.height))
   710→        const w = Math.max(1, Math.round(img.width * scale))
   711→        const h = Math.max(1, Math.round(img.height * scale))
   712→        const canvas = document.createElement('canvas')
   713→        canvas.width = square ? max : w
   714→        canvas.height = square ? max : h
   715→        const ctx = canvas.getContext('2d')
   716→        if (!ctx) return reject(new Error('پردازش تصویر پشتیبانی نمی‌شود'))
   717→        ctx.fillStyle = '#ffffff'
   718→        ctx.fillRect(0, 0, canvas.width, canvas.height)
   719→        if (square) {
   720→          const side = Math.min(img.width, img.height)
   721→          ctx.drawImage(img, (img.width - side) / 2, (img.height - side) / 2, side, side, 0, 0, max, max)
   722→        } else {
   723→          ctx.drawImage(img, 0, 0, w, h)
   724→        }
   725→        // فشرده‌سازی تطبیقی تا زیر ۳۰۰KB
   726→        for (const q of [0.85, 0.72, 0.6, 0.5]) {
   727→          const out = canvas.toDataURL('image/jpeg', q)
   728→          if (out.length <= 300 * 1024) return resolve(out)
   729→        }
   730→        resolve(canvas.toDataURL('image/jpeg', 0.42))
   731→      }
   732→      img.src = String(reader.result)
   733→    }
   734→    reader.readAsDataURL(file)
   735→  })
   736→}

   738→function randomStyle(): AvatarStyle {
   739→  const pick = <T,>(arr: readonly T[]): T => arr[Math.floor(Math.random() * arr.length)]
   740→  const biased = <T,>(items: readonly T[], noneVal: T, noneChance: number): T => (Math.random() < noneChance ? noneVal : pick(items))
   741→  return {
   742→    skin: Math.floor(Math.random() * AVATAR_SKINS.length),
   743→    hair: pick(AVATAR_HAIRS.filter((h) => h.k !== 'bald')).k,
   744→    hairColor: Math.floor(Math.random() * AVATAR_HAIR_COLORS.length),

   748→    outfitColor: Math.floor(Math.random() * AVATAR_OUTFIT_COLORS.length),
   749→    accessory: biased(AVATAR_ACCESSORIES.filter((a) => a.k !== 'none'), AVATAR_ACCESSORIES[0], 0.55).k,
