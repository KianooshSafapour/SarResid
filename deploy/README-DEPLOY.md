# استقرار نسخهٔ سوم (مهر+) + SSL — راهنمای سریع

## چه چیزی در این نسخه است
- سیستم کامل کاربر و دسترسی (RBAC) با تنظیم دسترسیِ تک‌تک صفحات و توانایی‌ها برای هر کاربر (system/users)
- سفارش‌گذاری بازطراحی‌شده: نتیجهٔ جستجوی سریع در جدول حرفه‌ای RTL با دکمهٔ ± عدد و ± کارتن در هر ردیف + انتخاب طرف حساب + تاریخ‌گیر شمسی
- مرجوعی: کارت بانکی در تسویه با کالا غیرفعال؛ رسید حرارتی درشت‌تر با بارکد و حروف‌خوانی مبلغ؛ سابقهٔ مشتری جمع‌شده با دیالوگ کامل
- تور خوش‌آمدگویی: فقط بار اول + درست‌شدن تاریکی و جهت فلش‌ها + ۱۱ تور تعاملی در «راهنما و دانش‌نامه»
- تاریخ‌گیر شمسی سراسری (همهٔ ورودی‌های تاریخ، حتی صفحات قدیمی)
- میزکار جدید با شخصی‌سازی ویجت‌ها (خانه/گروه‌بندی پژوهش‌محور: روز من/وضعیت فروشگاه/تیم)
- بررسی تیم: حذف چک‌باکس حضور + ساعت:دقیق برای تأخیر/مرخصی ساعتی/اضافه‌کاری
- گزارش تحویل شیفت ساخت‌یافته (۶ بخش + سنجه‌های خودکار + تأیید دریافت) و سیستم مشکلات کامل
- نقشهٔ واقعی ذوزنقه‌ای فروشگاه (۱۵٫۳۲×۲۰٫۱۰ متر با درگاه‌های فرورفته ورودی/خروجی) + ستون‌بندی بخش‌ها برای کنترل چرخشی تاریخ
- اتصال هلو: یکپارچه‌سازی کامل + شبیه‌ساز هلو (port 3040) برای آزمایش پیش از خرید API
- حساب کاربری شخصی (تغییر رمز/PIN/پروفایل) + چاپ حرفه‌ای اسناد (A4/PDF)

## مراحل (روی سرور — یک‌بار)

```bash
# ۱) بسته را به سرور ببرید (از سیستم خودتان):
scp deploy/sarresid-r3-*.tar.gz deploy/deploy-r3.sh deploy/setup-ssl.sh root@195.248.241.14:/root/

# ۲) روی سرور:
ssh root@195.248.241.14
cd /root && bash deploy-r3.sh            # استقرار کامل (پشتیبان + کد + اسکیما + بیلد + سرویس‌ها)
bash setup-ssl.sh                        # گواهی رایگان Let's Encrypt برای sarresid.hyperzeytoon.com
```

بعد از `deploy-r3.sh` دوباره بستهٔ جدید بسازید (deploy/make-package.sh) و `deploy-r3.sh` دوباره اجراکنید — اسکریپت‌ها idempotent هستند.

## نکته‌ها
- دیتابیس سرور دست نمی‌خورد؛ فقط اسکیمای جدید push می‌شود (قبلش از db/custom.db پشتیبان گرفته می‌شود در /root/backups)
- شبیه‌ساز هلو به‌صورت سرویس systemd (holoo-sim) روی port 3040 بالا می‌آید — پیش‌فرض تنظیمات «حالت شبیه‌ساز» فعال است؛ بعد از خرید API واقعی هلو فقط در «سیستم ← اتصال هلو» حالت را روی «سرور واقعی» بگذارید و نشانی وب‌سرویس را وارد کنید
- تمدید گواهی خودکار است (acme.sh cron هر ۶۰ روز)
- اگر صدور گواهی شکست خورد: مطمئن شوید port 80 از بیرون باز است و DNS دامنه به 195.248.241.14 اشاره می‌کند (الان اشاره می‌کند ✓)
