Status flow: assigned→in_progress→done→verified | blocked | cancelled. done sets doneAt; verify sets verifiedBy/At. Every action → notify the other party.
2. `staff-checks/route.ts`
   - GET `?date=1405-07-27&shift=MORNING|EVENING` → `{checks:[...], staff:[{id,fullName,honorific,role,title} active non-manager staff], unresolvedMorning:[{id,title,detail,severity,createdAt} open Problems from MORNING of that date]}`. Managers only.
   - POST `{date, shift, rows:[{staffId, present, arrival(on_time|late|absent|permitted_leave), lateMinutes, hadPermission, uniform(ok|needs_followup), hygiene(ok|needs_followup), behavior(ok|needs_followup), workQuality(ok|needs_followup), note?}]}` → upsert per staff (unique date+shift+staffId) `{saved:n}`.

3. `section-reviews/route.ts`

All managers + PM.
   - POST `{date, lineId, blockLabel, checkerId, checkerName, status(ok|issues), expiredCount, nearExpiryCount, fefoOk, action?, note?}` → `{check}` (upsert unique date+lineId).
